# rollHeroRe Demo — 功能介绍

> 面向**使用者（策划 / 体验者）**：介绍这个 Demo 有哪些系统、每个系统怎么玩、规则是什么。
> 想改代码或改配置请看《开发文档.md》。

---

## 一、这个 Demo 是什么

一个**单机网页 Demo**，用来验证「**选人 → 走地图 → 骰子驱动战斗**」这条核心循环的手感与数值。

- 形态：单个 `web/index.html`（配置以 JSON 形式内嵌，无需后端即可双击打开）。
- 内容规模：5 名可选英雄、4 种怪物、2 张已配置地图、13 条已配置技能。
- 目的：验证规则与数值，**不是**成品 UI。立绘、技能图标、骰子均为 emoji 占位。

### 启动方式

| 方式 | 操作 | 说明 |
|---|---|---|
| **推荐** | 双击根目录 `start_map_demo.bat` | 启动本地服务并打开 `http://127.0.0.1:8765/`，可用页面上的「刷新配置」按钮 |
| 简易 | 直接双击 `web/index.html` | 能玩，但「刷新配置」按钮不可用（浏览器禁止 `file://` 调脚本） |

启动后三个界面依次串起来：**选人 → 地图 → 战斗**（战斗结束回到地图）。

## 二、界面一：选择出击阵容

从 5 张英雄卡里选出 **3 名**出战（人数由配置 `initTeamSize` 决定）。

卡面信息（全部来自配置表，非硬编码）：

| 区域 | 内容 |
|---|---|
| 顶部左 | 职业（战士 / 守卫 / 弓箭手 / 法师 / 牧师） |
| 顶部右 | ❤ 基础血量 |
| 中部 | 立绘（emoji 占位）+ 中文名 |
| 中部下 | **6 个骰面宝石**（颜色 + 点数），决定投骰子阶段能掷出什么 |
| 底部 | 最多 2 条技能：技能名 + 消耗宝石 + 效果描述 |

交互：

- 点卡片 = 选中/取消；选满后再点会**抖动拒绝**。
- 选中顺序 = 出战顺序 = 布阵时的初始站位顺序（1/2/3 号位）。
- 底部 4 个按钮：`挑战模式`（未开放）、`出击`（选满后高亮）、`晋升图鉴`（未开放）、`刷新配置`（重新从 Excel 导出配置并刷新页面）。

## 三、界面二：地图关卡

### 3.1 棋盘

- 编号 **1–33**，按 5 列一行排布（1–5 为 L1，6–10 为 L2 … 31–35 为 L7），行内做错位视觉偏移呈「蜂窝」观感。
- **不存在的格子**（如 26、30、31、32）显示为空白；配置里跳号即可。
- 从 **3 号格（出生点 🚩）** 出发。

### 3.2 格子类型

| 图标 | 类型 | 行为 |
|---|---|---|
| ⚔️ | `battle` 战斗 | 进入普通战斗 |
| 🔥 | `battleHigh` 精英战斗 | 进入精英战斗（站位区块更大） |
| 👑 | `battleBoss` BOSS 战斗 | 胜利后进入下一章节地图的 3 号格 |
| 🪙 | `coin` 金币 | 直接领金币 |
| 🎁 | `randWeapon` 随机装备 | 记入日志（背包未实现） |
| ⛰️ | `rock` 山石 | 不可点选、不可通行 |
| 🚩 | `start` 出生点 | 无事件 |

### 3.3 移动规则（核心）

按**当前格编号 `here % 5`** 分档决定候选格：

| 余数 | 可移动到 |
|---|---|
| 余 1 | `+5` / `+6` |
| 余 2 | `-1` / `+5` / `+6` |
| 余 3 | `-1` / `+5` / `+1` |
| 余 4 | `+4` / `+5` / `+1` |
| 余 0 | `+4` / `+5` |

过滤条件：编号存在、非 rock、未走过、**未被锁定**。

> **关键规则**：走到某格后，**本次其余候选格永久锁定 🔒**。走过的格子打 ✓。所以路线是一次性取舍，不能回头。

- 顶栏显示：章节、地图 tag、当前位置、🪙 金币、✨ 经验。
- 右栏三块面板：出击阵容、当前可选格子（含规则说明）、事件日志。
- `重新开始`：回到选人界面，保留已选阵容。
- 走到死路（无候选）时提示无路可走，需重开。

## 四、界面三：战斗

战斗分**三个阶段**依次推进：`布阵 → 投骰子 → 开战`（开战后每回合回到投骰子）。

### 4.1 战场布局

```
敌方阵营  3 行 × 5 列（X=行，1 最靠近我方；Y=列，1 最左）
          ── 实际可用格由「站位区块」配置决定，未启用格隐藏
我方阵营  2 行 × 3 列（居中放置）
          0/1/2 号位 = 第 1 行（远），3/4/5 号位 = 第 2 行（近，贴敌）
```

- 站位区块有两档：`battle`（13 格，远处收窄）与 `battleHigh`（15 格，满格）。
  普通战斗用 `battle`，精英/BOSS 用 `battleHigh`（**BOSS 暂无专属区块，暂用 battleHigh**）。

### 4.2 阶段一：布阵

- 我方默认按选人顺序占据 1/2/3 号位。
- **拖拽**我方英雄格可换位（含空槽），单位状态随槽位一起交换。
- 敌方阵容：从格子的 `battleContent`（如 `battle1,battle2`）里**等概率随机抽一档**，按 `battleScene` 表的站位摆放。
- 点「布阵结束」进入投骰子阶段。

### 4.3 阶段二：投骰子

- 每个上场英雄掷 **1–6 点**，命中自己 6 个骰面宝石中的对应面，得到「颜色 + 点数」。
- 顶栏汇总四种颜色的总点数：⚔️红 / 🛡️蓝 / ⛏️绿 / ⭐黄。
- **点击骰子可锁定 🔒**，重投时锁定面不变；**每回合最多重投 2 次**。
- 悬停骰子可看该英雄 6 个面分别会掷出什么（当前面金框高亮）。
- 骰子点数**只决定本回合技能能否解锁，释放时不消耗**——同回合可释放多个技能，只要点数够。
- 全部技能解锁时顶栏呼吸切换为「所有技能都已解锁」。
- 点「开 战」进入开战阶段。

### 4.4 阶段三：开战（回合制）

每个回合固定流程：

```
① 我方 auto 技能自动释放
② 敌方全体按站位顺序「瞄准」并锁定目标（每回合重瞄）
③ 我方逐个释放 choose 技能（可点【结束行动】跳过）
④ 敌方按瞄准顺序依次生效（目标已阵亡则落空）
⑤ 下一回合 → 重新投骰子
```

**技能两类**：

| useType | 行为 |
|---|---|
| `auto` | 回合开始自动释放，目标按规则自动选定（如「格挡」自动给自己加护甲） |
| `choose` | 玩家点左栏技能图标 → 点战场目标释放；每个技能每回合各可放一次 |

**玩家操作流程**：

1. 点左栏某个英雄的**技能图标**（金框=选中；再点同一图标取消；点战场外空白也取消）。
2. 战场出现**红色范围外沿框**标出技能完整作用区。
3. 悬停有效目标：高亮 + 显示预览；悬停无效目标：飘字「不能对该目标释放」。
4. 点击释放。已放过的技能图标置灰；该英雄无可用技能时整行置灰（acted）。

> **点选格 = 范围中心**，允许点在空格（如横扫点在两个敌人之间的空位），预览与实际生效口径一致。

### 4.5 预览系统（本 Demo 的重点）

| 预览 | 触发 | 表现 |
|---|---|---|
| **敌方瞄准持续预览** | 开战即常驻 | 被瞄准单位血/盾条上：虚化闪动段=将失去、浅色段=将获得；数字显示「当前→结算后」；✕=血条将致死；☠=死亡预告 |
| **瞄准指示线** | 未选技能时悬停敌方 | 虚线曲线 + 箭头指向其锁定目标，并在我方目标上叠加同款伤害预览 |
| **技能效果预览** | 选中技能后悬停目标 | 范围外沿红框 + 大号伤害数字 + 逐单位血/盾变化 + 致死红叉 |
| **释放反馈** | 技能生效时 | 血/盾条宽度动画过渡、伤害飘字（-N）、护甲飘字（+N 🛡）、受击闪动、施法晃动、阵亡淡出 |

预览会**实时重算**：瞄准者被打死 → 其份额剔除；目标死亡 → 预览消失；我方护甲变化 → 伤害同步变化。

### 4.6 结算规则

- **伤害** = 技能 `dmg` + `dmgShieldPara` × 释放者当前护甲（护甲只作加成，**不消耗**）。
- **扣减顺序**：先扣护甲，溢出部分扣血。
- **护甲**：我方辅助技加给目标；敌方「敌方向」技能加给释放者自己。
- 单位血/盾条：我方绿条、敌方红条，护甲为蓝色附条，数字叠在条上。
- **胜负**：敌方全灭 → 胜利并发放格子奖励；我方全灭 → 失败，返回地图无奖励。
- 战斗失败**无惩罚**，下一场战斗血量重新按基础值初始化。
- BOSS 胜利 → 进入下一章节（tier+1）地图的 3 号格。
